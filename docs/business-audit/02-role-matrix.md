# Role and permission matrix

Role source: `database/schema.sql:16` enum and `middleware/authMiddleware.js:6-14`. No `operator` or `staff` role is in the enum/session role map. HQ has a staff-management feature, but staff are not mapped to an authenticated app role (`routes/hq.js:25-27`; `controllers/hqController.js` staff handlers). Guest means unauthenticated captive-portal caller, not a DB role.

| Actor | Creation/auth/approval | Backend enforcement and data scope | Suspension/deletion/resource effects |
|---|---|---|---|
| `super_admin` | Admin login/session; account provisioning is admin-side. | Admin middleware and admin route groups enforce role; broad global access. | Can manage routers/users/locations/finance; deletion consequences vary by FK and external cleanup. |
| `admin` | Admin login/session; approval flows in admin APIs. | Same broad admin route access as super_admin in most middleware; no finer privilege split consistently visible. | Customer suspend/delete flows in `adminLegacy` and admin controller; router side-effect path includes pending retry. |
| `sponsor` | Partner application/public intake and sponsor registration/auth; campaign approval may be required. | `sponsorAuth` accepts sponsor plus bank/admin; campaign handlers filter by owner in some queries, but inspect each endpoint. | Campaigns reference users with cascade delete; budget/reward rollback not guaranteed as one transaction. |
| `bank_partner` | Application/admin conversion and bank login. | `bankAuth`; shares sponsor campaign permission wrapper. | Campaign and lead data are user-owned by ID; deletion cascades campaigns. |
| `franchise_owner` | Application/admin assignment; franchise login. | `franchiseAuth`; `getLocationPerformance` checks `franchise_owner_id`; `getMyLocations` scopes by owner. | Location FK sets owner NULL on deletion; router reference persists via location FK policy. No organization-wide suspend behavior. |
| `reseller` | Reseller application/approval, registration and login (`routes/reseller.js`, `resellerApplications.js`). | `resellerAuth` also allows admin; reseller controller generally selects by authenticated user. Audit each specific operation; no universal tenant model. | Reseller suspension/status and withdrawals exist; user deletion cascades reseller row and withdrawal history. Voucher batches created_by cascade can delete batch; voucher FK sets batch NULL. |
| `investor` | Investor account/admin process; login. | `investorAuth` also accepts admin, franchise owner. Investor queries filter by `req.user.id` (`controllers/investorController.js:17-30,95`). | Investment FK cascades returns. No payout/funding execution established by these reads. |
| `customer` | Captive portal registration/login; no administrator approval required for ordinary customer. | Customer session auth for account-specific flows; Wi-Fi portal routes deliberately allow guest context. RADIUS `authorize` checks `is_active` and entitlement (`hotbando_auth.pl:80-91`). | Suspend flips active status and router cleanup queues retry; delete FK behavior varies, pending revocations intentionally survive. |
| `guest` | No account/auth; Wi-Fi/captive portal presence. | `requireWifi` is network context, not identity. Public packages, payment preview, voucher/gift flows are exposed; receipt token protects guest status/confirm. | No owned DB resources until registration/payment order. Payment voucher purchase is a guest path. |

Finding (P1): Frontend route metadata supplements role hiding but cannot secure APIs. Ensure every route uses backend auth and resource-level ownership. Evidence: `frontend/src/router/index.js`; API groups in `routes/*`; `routes/locationRoutes.js:24-35` combines franchise and admin access with handler-level ownership on performance. Tables: `users.role`, `locations.franchise_owner_id`. Proposed fix in later stage: per-route audit and owner checks, not a new role/tenant model.

Finding (P2): Staff management exists as HQ records, but not an authenticated staff/operator role. Evidence: `routes/hq.js:25-27`, user enum `database/schema.sql:16`, session map `middleware/authMiddleware.js:6-14`. Frontend entry: `views/admin/Staff.vue`. Expected role policy is UNDEFINED BUSINESS RULE. Impact: cannot represent least-privilege branch operators. Proposed fix only after policy decision.
